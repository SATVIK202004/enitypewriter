How to Use

Six steps. Five minutes. Zero stress.

1

Download & Run the .exe

Download ENI_Typewriter.exe from the Releases section. Double-click. A window appears with a QR code and URL. Your laptop is now a server.

2

Connect Your Phone

Phone on same Wi-Fi as laptop. Scan the QR code on screen with your camera — or type the URL into Chrome/Safari manually.

3

Add to Home Screen

Chrome: ⋮ → "Add to Home Screen". Safari: Share → "Add to Home Screen". Opens full-screen — no browser bars.

4

Paste Code & Type

Copy code to phone clipboard. Open app → tap text area (auto-pastes). Click into exam editor on laptop. Tap ⚡ TYPE IT.

5

STOP Anytime

Mid-type issue? Tap ■ STOP. Typing halts in 0.5s. Button reappears. Correct the code. Retry. No penalty.

6

Close When Done

Click Stop Server or close the window. Phone disconnects. No traces. No logs. Done.
